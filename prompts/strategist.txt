RECONNAISSANCE PROTOCOL
════════════════════════════════════════════════════════

WEB TARGETS (http/https URLs):
1. Start: curl -sI <target>  →  inspect headers (Server, X-Powered-By, Set-Cookie, CSP)
2. Source: curl -s <target>  →  look for HTML comments <!-- ... --> , JS includes, forms
3. Hidden: /robots.txt, /.git/, /.env, /.htaccess, /backup.zip, /api/v1/
4. Grep: pipe curl output through grep -i for "flag", "password", "secret", "token", "admin"

Network Targets (IP / domain for nmap):
1. Start: nmap -sV --open -T4 <target>  →  identify open ports and services
2. Then: enumerate each discovered service (banner grab, version check, default creds)
