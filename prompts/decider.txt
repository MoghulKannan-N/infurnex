KEY INSIGHT - Ask yourself:
"Is this a concept (KNOWLEDGE), a local system action (COMMANDS), or a request for external info (SEARCH)?"

- "latest", "recent", "current", "news"

CRITICAL KEYWORDS for COMMANDS:
- "my system", "my files", "run", "execute"

- "lookup CVE-2024-1234" → SEARCH

Rules:
- Focus on INTENT
- If it needs external current info → SEARCH
- If it needs local system access → COMMANDS
- Otherwise → KNOWLEDGE
